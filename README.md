# Unscramble — Tugas 8 PPB

Project Android **Unscramble** untuk Tugas 8: **Arsitektur Aplikasi (UI Layer) & Android Jetpack Components**.

## Teknologi
- Kotlin
- Jetpack Compose
- Material 3
- ViewModel
- StateFlow
- Lifecycle Compose
- MVVM-style UI state management
- Minimum SDK 24

## Struktur utama
```text
app/src/main/java/com/example/unscramble/
├── MainActivity.kt
├── data/
│   └── WordsData.kt
└── ui/
    ├── GameScreen.kt
    ├── GameUiState.kt
    ├── GameViewModel.kt
    └── theme/
```

Project dapat dibuka langsung menggunakan Android Studio dan dijalankan pada emulator/perangkat Android.
